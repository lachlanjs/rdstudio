# Idea

* [Distribution, funding and naming](distribution-and-naming.md) - Self-hosting by default under MIT, optional paid convenience or donations, the user always free to bring their own AI, and name candidates for an agentic harness for learning.
* [Per-agent model and harness settings](future-agent-settings.md) - Future feature for choosing model, provider, thinking level and tool permissions per agent profile.
* [Testing on real phones](device-testing.md) - How the end-to-end checks could run closer to real Android and iOS devices than headless Chromium with a phone-sized window, and what each way needs.
* [Project mode: watching an agent's path through the base, and an agent in the editor](project-agent-features.md) - Two ideas from the developer for project mode: show which notes an agent reads and writes as it works, as a path on the Atlas; and let the person editing a note ask an agent about a passage or have it fill one in.
* [Themes: Arbo, Carto, Sevasto, Termo, Metro](themes.md) - Five theme ideas from the developer, each a whole look for the app and its Atlas: a tree, a cartographic map, the Alien: Isolation terminal (built, as Station), an ASCII terminal, and a subway map.
* [Zotero annotations into reference concepts](zotero-annotations.md) - Pull highlights and notes made in Zotero into each Reference concept, so reading work becomes searchable knowledge.
