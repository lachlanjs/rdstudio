# Teach

How to teach is kept by rdstudio, not here: the developer may have
customised it, privately. Read it through the rdstudio MCP tools.

1. `teacher_skills` lists the skills, with the profile (topic, codebase or
   project) and which skills the developer has customised.
2. `teacher_skill` with `name: "teach"` gives the rules every skill keeps.
   Read it first, each session.
3. Then read the skill for the job (`assess`, `map`, `source`, `exercise`,
   `next`, `review-changes`) and follow it.

If the tools say the learner record is off, say so: the developer turns it
on with `[learner] enabled = true` in `~/.config/rdstudio/config.toml`.
