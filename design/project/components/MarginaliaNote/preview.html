Variance scaling

A sum of NNN independent terms has NNN times the variance of one term. So for the recurrent input to stay the same size as the network grows, each weight has to shrink: its variance must be g2/Ng^2/Ng2/N, the step the cavity method takes for granted.

The calculation

With Jj=±g/NJ_j = \pm g/\sqrt{N}Jj​=±g/N​ and E[y2]=q\mathbb{E}[y^2] = qE[y2]=q, the terms JjyjJ_j y_jJj​yj​ are independent with mean 000, so their variances add:

Var(h)=∑j=1NVar(Jjyj)=N⋅g2N q=g2q.\mathrm{Var}(h) = \sum_{j=1}^N \mathrm{Var}(J_j y_j) = N \cdot \frac{g^2}{N}\, q = g^2 q.Var(h)=j=1∑N​Var(Jj​yj​)=N⋅Ng2​q=g2q.

The NNN from the sum cancels the 1/N1/N1/N from each weight. By the central limit theorem, hhh is then approximately Gaussian with a variance that does not depend on NNN.

Check it numerically

recurrent_input returns one sample of hhh per trial.

pythonimport numpy as np

def recurrent_input(N, g=1.5, q=1.0, trials=10_000, seed=0):
    rng = np.random.default_rng(seed)
    J = rng.choice([-1.0, 1.0], size=(trials, N)) * g / np.sqrt(N)
    y = rng.normal(0.0, np.sqrt(q), size=(trials, N))
    return (J * y).sum(axis=1)

for N in (10, 100, 1000):
    print(N, recurrent_input(N).var())  # near g**2 * q = 2.25
